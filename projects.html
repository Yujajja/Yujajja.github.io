01
Team Project 2026.04.13 ~ 2026.05.14 Infra / Monitoring

북적북적 — 하이브리드 기반 AI 도서 추천 서비스

온프레미스 Kubernetes를 메인 서비스 영역으로, AWS EKS를 Failover 영역으로 구성한 팀 프로젝트에서 모니터링 대시보드, 알림, 부하·장애 실험을 담당했습니다.

AWS EKSKubernetesPrometheusGrafana AlertManagerLocustChaos MeshRedis

기여한 부분

  • Prometheus·Grafana 기반 모니터링 대시보드를 구성했습니다.
  • AlertManager와 Slack을 연동해 장애 알림 흐름을 구현했습니다.
  • Locust와 Chaos Mesh로 CPU·Memory 부하 및 Redis 장애를 검증했습니다.

검증 및 개선 결과

HPA 2 → 3개 확장 · 에러율 0% 유지

Memory StressChaos의 OOMKill 원인을 분석하고 부하 주입량을 조정해 에러율을 5.41%에서 0%로 개선했습니다.

장애 실험

Redis 장애 시 Cache Hit율이 100%에서 0%로 감소하고 평균 응답시간이 증가하는 현상과 Slack Alert 수신을 확인했습니다.

AWS Security Auto Remediation — 보안 그룹 위험 규칙 자동 조치

보안 그룹에 위험한 SSH 규칙이 추가되는 이벤트를 감지하고, Lambda가 해당 규칙을 자동으로 되돌리는 보안 대응 흐름을 구현했습니다.

CloudTrailEventBridgeLambdaSecurity Group AWS ConfigCloudWatch LogsSNSTerraform

핵심 구현

  • CloudTrail의 AuthorizeSecurityGroupIngress 이벤트를 기록했습니다.
  • EventBridge가 0.0.0.0/0 SSH 오픈 이벤트를 탐지하도록 구성했습니다.
  • Lambda가 위험 규칙을 제거하고 CloudWatch Logs와 SNS에 결과를 남겼습니다.

보안 운영 관점

탐지와 자동 조치를 분리한 이벤트 기반 구조

AWS Config로 별도 테스트 보안 그룹의 NON_COMPLIANT 상태를 확인하고, S3 Audit Bucket에 감사 로그를 보관했습니다.
